Les box FamilyDrive

Une box est un espace de fichiers séparé. Chaque box possède 30 Go gratuits, son propre contenu et un code de partage.

  1. Créez une box et donnez-lui un nom.
  2. Copiez son code et envoyez-le aux personnes de confiance.
  3. Les personnes saisissent ce code pour rejoindre la même box.
  4. Chaque membre peut ensuite consulter et gérer les fichiers de cette box.

Le code permet de rejoindre la box. Gardez-le privé et partagez-le uniquement avec votre famille.
